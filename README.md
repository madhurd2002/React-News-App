# 📰 NewsPulse – React News App

NewsPulse is a responsive news application built with **React.js** that allows users to browse the latest news based on different categories such as Technology, Business, Health, Sports, and Entertainment.

The application fetches real-time news articles using the **NewsAPI** and provides users with a simple and responsive interface to explore news.

## 🚀 Features

- 📰 Latest news articles
- 🔥 Category-based news filtering
- 💻 Technology news
- 💼 Business news
- 🏥 Health news
- ⚽ Sports news
- 🎬 Entertainment news
- 🔗 Read More option to view the complete article
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🖼️ Fallback image when an article doesn't contain an image
- ⚡ Dynamic news fetching using React Hooks
- 🍔 Responsive navigation bar with Bootstrap

## 🛠️ Technologies Used

- **React.js**
- **JavaScript**
- **Bootstrap**
- **NewsAPI**
- **Vite**
- **HTML5**
- **CSS3**
